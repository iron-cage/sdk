# src/components/icons

Thin SVG icon wrapper components. Each file exports a single `<svg>` element as a Vue component and accepts standard HTML attributes via `$attrs`.

| File | Icon |
|------|------|
| `IconArrowDownToLine.vue` | Arrow pointing down to a horizontal line |
| `IconArrowUpFromLine.vue` | Arrow pointing up from a horizontal line |
| `IconBan.vue` | Ban / block circle |
| `IconBarChart.vue` | Bar chart |
| `IconCheck.vue` | Checkmark |
| `IconCheckCircle.vue` | Checkmark inside a circle |
| `IconChevronDown.vue` | Downward-pointing chevron |
| `IconChevronLeft.vue` | Left-pointing chevron |
| `IconChevronRight.vue` | Right-pointing chevron |
| `IconChevronUp.vue` | Upward-pointing chevron |
| `IconChip.vue` | Microchip / processor |
| `IconClipboard.vue` | Clipboard |
| `IconCog.vue` | Settings gear |
| `IconCoin.vue` | Coin / currency |
| `IconCopy.vue` | Copy to clipboard |
| `IconDotsHorizontal.vue` | Three horizontal dots (overflow menu) |
| `IconDownload.vue` | Download arrow |
| `IconEdit.vue` | Pencil / edit |
| `IconGrid.vue` | Grid layout |
| `IconHome.vue` | Home / dashboard |
| `IconKey.vue` | Key / token |
| `IconLogIn.vue` | Log in arrow |
| `IconLogOut.vue` | Log out arrow |
| `IconMenu.vue` | Hamburger menu |
| `IconPlus.vue` | Plus / add |
| `IconRefresh.vue` | Refresh / rotate arrows |
| `IconServer.vue` | Server rack |
| `IconTrash.vue` | Trash / delete |
| `IconUsers.vue` | Multiple users |
| `IconX.vue` | Close / dismiss X |
