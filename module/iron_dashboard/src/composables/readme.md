# src/composables

Vue composables that encapsulate reusable stateful logic.

| File | Purpose |
|------|---------|
| `useApi.ts` | Typed API client wrapping all backend HTTP calls |
| `useClipboard.ts` | Clipboard copy helper with graceful toast feedback when unsupported |
| `useConfirm.ts` | Reusable confirm-dialog state shared across views |
